# 虎牙直播 → PotPlayer 本地中继

> 把虎牙直播间转成一个本地播放地址，用 **PotPlayer / VLC / mpv** 直接看。
> **1080p60 原画质 · 不掉帧 · 有声音 · 双击即用。**

---

## 这玩意儿解决什么问题？

虎牙网页版看直播没问题，但你想用 PotPlayer 这类本地播放器看，会发现：

- 复制出来的直链粘进播放器 → **「服务器已关闭连接」**，播几秒就断
- 好不容易能播 → **画面掉帧**，60 帧的流看着像 25 帧
- 想自己转一下 → **没声音了**，或者声音变成单声道

原因很简单：虎牙的 CDN 对匿名请求是**按块发**的，一条连接只给你 2~8 秒就掐断。播放器没法自己把这些碎块拼起来。

本程序在你自己电脑上开一个「中转站」，把碎块拼成连续流再喂给播放器：

```
虎牙 CDN（2~8 秒碎块）
      ↓  本程序并发拉取、去重、补齐
http://127.0.0.1:8765/live.m3u8   ← 播放器打开这个
      ↓
PotPlayer / VLC / mpv
```

## ⚡ 快速开始（3 步，约 3 分钟）

### 第 1 步：装 Node.js

打开 **https://nodejs.org/** ，点那个写着 **LTS** 的大按钮（推荐版本）。

下载完双击，然后 **一路点「Next」到底**，中途什么都不用改。

> ⚠️ 装完**建议重启一次电脑**，否则新装的命令可能还没生效。

**怎么确认装好了？**

按 `Win + R`，输入 `cmd` 回车，在黑窗口里输入：

```bat
node -v
```

看到 `v18.x.x` 或 `v20.x.x` 或 `v22.x.x` 这种（**16 以上都行**）就成功了。
如果提示「不是内部或外部命令」，说明没装好或者没重启 —— 回去重装一遍。

---

### 第 2 步：下载本项目

**方法 A（推荐，简单）**

在 GitHub 页面点绿色 **`Code`** 按钮 → **`Download ZIP`** → 解压到任意文件夹。

**方法 B（会用 git 的话）**

```bat
git clone https://github.com/NZNL31/huya-potplayer-relay.git
```

> 💡 **解压路径别带中文和空格**，比如 `D:\huya` 就很好。
> `D:\我的软件\虎牙 直播\` 这种路径偶尔会出问题，避开它。

---

### 第 3 步：双击运行

进到解压后的文件夹，**双击 `play-huya.bat`**。

会弹出一个黑窗口，问你房间号：

```
==========================================
        虎牙直播  -  PotPlayer
==========================================

  请输入直播间，支持三种写法：

    房间号      825803
    房间名      dank1ng
    完整链接    https://www.huya.com/825803

  上次使用: 825803   （直接回车沿用）

  请输入房间: _
```

**房间号在哪找？** 打开虎牙网页版，进任意直播间，看浏览器地址栏：

```
https://www.huya.com/825803        ← 825803 就是房间号
https://www.huya.com/dank1ng      ← dank1ng 是房间名，也可以
```

直接**把整个网址粘进去也行**，程序会自动提取。

输入完回车 → 问画质 → 问模式 → **一路回车**（默认就是最佳配置）→ PotPlayer 自动打开开始播。

> 🔴 **重要：播放期间别关那个黑窗口。**
> 关了 = 停止播放。想停止看播，关掉黑窗口就行。

## ✅ 30 秒自检

出问题时对着这张表看一眼，八成能自己解决：

| 检查项 | 怎么查 | 正常表现 |
|--------|--------|---------|
| Node.js 装了吗 | cmd 里输 `node -v` | 显示 `v16` 或更高 |
| 双击没反应 / 一闪而过 | 右键 `play-huya.bat` → 编辑 | 能看到里面几行命令，不是乱码 |
| ffmpeg 有没有 | 不用管 | 装了 PotPlayer 就自动有；没装也能跑 |
| PotPlayer 有没有 | 不用管 | 没装的话程序会打印地址，你手动打开 |

**ffmpeg 是什么？需要单独装吗？**

<details>
<summary>点开看（不想看可以跳过，不影响使用）</summary>

ffmpeg 是个转码工具，本程序用它把流切成 HLS 分片。

**如果你装了 PotPlayer，它自带 ffmpeg**，本程序会自动去这几个位置找，你什么都不用做：

- 脚本同目录 / 上一级目录
- `C:\Program Files\DAUM\PotPlayer\Engine\`
- 系统 `PATH` 环境变量里

**如果程序提示「找不到 ffmpeg」**，那就装一个：

1. 打开 https://www.gyan.dev/ffmpeg/builds/
2. 下载 `ffmpeg-release-essentials.zip`
3. 解压，把 `bin` 文件夹里的 **`ffmpeg.exe`** 复制到**本项目的同一个文件夹**里

搞定。

</details>

## 🎮 使用说明

### 输入房间的三种写法

| 写法 | 例子 | 说明 |
|------|------|------|
| 房间号 | `825803` | 最常用，一串数字 |
| 房间名 | `dank1ng` | 英文房间名（自定义域名那种） |
| 完整链接 | `https://www.huya.com/825803` | 直接粘网址，最省事 |

上次用过的房间会记在 `last-room.txt` 里，**下次直接回车就能沿用**。

### 画质怎么选

| 选项 | 是什么 | 什么时候选 |
|------|--------|-----------|
| `[1]` 蓝光8M | 1080p / 60 帧 / 高码率 | ✅ **默认选这个**，画质最好 |
| `[2]` 蓝光4M | 1080p / 30 帧 / 中等码率 | 网络不太行、或者 8M 卡的时候 |
| `[3]` 超清2M | 720p 级别 | 网络很差，只求能看 |

> 📶 8M 档实际峰值能到 **15Mbps** 左右。家里带宽 20M 以下建议选 4M。

### 模式怎么选

| 选项 | 画质 | 流畅度 | 延迟 | 什么时候选 |
|------|------|--------|------|-----------|
| `[1]` 原画直通 | 无损 ⭐⭐⭐⭐⭐ | 好 ⭐⭐⭐⭐ | 约 5 秒 | ✅ **默认选这个** |
| `[2]` 流畅优先 | 轻微二次编码 ⭐⭐⭐⭐ | 最好 ⭐⭐⭐⭐⭐ | 约 7 秒 | 原画模式看着还有点顿的时候 |
| `[3]` 低延迟 | 无损 ⭐⭐⭐⭐⭐ | 一般 ⭐⭐⭐ | 约 3 秒 | 看比赛，要跟弹幕/聊天室同步 |

**记住一句话**：先全回车用默认。如果画面有轻微顿挫，再重新运行选 `[2] 流畅优先`。

### 想用别的播放器？

程序默认拉 PotPlayer。想用 VLC 或 mpv，在它问「是否打开 PotPlayer」时选否，然后自己打开这个地址：

```
http://127.0.0.1:8765/live.m3u8
```

- **HLS 地址**（推荐）：`http://127.0.0.1:8765/live.m3u8`
- **FLV 地址**（延迟更低）：`http://127.0.0.1:8765/live.flv`

## ❓ 常见问题

### 双击 bat，窗口一闪就没了

说明 Node.js 没装好，或者 `node` 命令不可用。

**解决**：按 `Win + R` → 输 `cmd` → 回车 → 输 `node -v`。
如果提示「不是内部或外部命令」，回去重装 Node.js，**装完重启电脑**。

---

### 提示「找不到 PotPlayer」

程序找不到播放器，但**流已经在中继了**，不影响你自己手动打开。

三种解决方式，选一种：

```bat
:: 方式 1：指定路径（把路径换成你自己的）
node huya-relay.js 825803 --player "D:\PotPlayer\PotPlayerMini64.exe" --open

:: 方式 2：设个环境变量，以后就不用管了
set POTPLAYER_PATH=D:\PotPlayer\PotPlayerMini64.exe

:: 方式 3：干脆不自动播，自己用播放器打开
node huya-relay.js 825803
:: 然后播放器里打开 http://127.0.0.1:8765/live.m3u8
```

---

### 提示「端口 8765 被占用」

上次的中继没退干净。程序一般会自动复用，如果还是不行，手动清掉：

```bat
:: 查是谁占着
netstat -ano | findstr :8765

:: 结束它（把 12345 换成上面查到的最后一列数字）
taskkill /PID 12345 /F
```

或者换个端口：双击时如果程序问端口，输 `8766`；命令行就加 `--port 8766`。

---

### 没有声音

**v2.4 已修复**。如果你用的是旧版，更新一下就好。

如果新版还是没声音，用 ffprobe 检查一下（本项目目录下运行）：

```bat
ffprobe -i http://127.0.0.1:8765/live.m3u8
```

- 看到 `Audio: aac (LC), 44100 Hz, stereo` → 音频正常，是播放器的问题，换个播放器试
- 看到 `mono` 或 `aac (LTP)` → ffmpeg 版本太老，升级到 4.0 以上

---

### 画面卡顿 / 掉帧

按这个顺序试，一般第 1 步就好了：

1. **换模式** → 重新运行，模式选 `[2] 流畅优先`（用显卡重编码，强制补齐帧率）
2. **降码率** → 画质选 `[2] 蓝光4M`
3. **看带宽** → `Ctrl+Shift+Esc` 打开任务管理器 → 性能 → 以太网，看占用有没有跑满
4. **换播放器** → mpv 对不连续流的容忍度比 PotPlayer 高

---

### 蓝光8M 反而比 4M 卡？

这不是错觉。虎牙不同码率档的 CDN 分块长度差很多（实测 8M 档一块只有 **2.4 秒**，4M 档有 **8 秒**）。块越碎，拼接难度越高。

网络一般的话，选 4M 反而更稳。

---

### 主播没开播

程序会提示 `主播当前未开播` 并一直重试。**别关窗口**，等主播开播它会自动接上。

---

### 能不能看多个房间？

可以，开多个黑窗口，每个用不同端口：

```bat
node huya-relay.js 825803 --port 8765 --open
node huya-relay.js dank1ng --port 8766 --open
```

## 🔧 进阶：命令行用法

不想用交互界面，直接命令行更快：

```bat
:: 最简单
node huya-relay.js 825803 --open

:: 指定画质 4M
node huya-relay.js 825803 --bitrate 4000 --open

:: 用完整链接
node huya-relay.js https://www.huya.com/dank1ng --open

:: 流畅优先（NVENC 重编码）
node huya-relay.js 825803 --transcode --open

:: 低延迟（FLV 直出，不转 HLS）
node huya-relay.js 825803 --flv --open

:: 换端口
node huya-relay.js 825803 --port 8766 --open
```

### 全部参数

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `<房间>` | `dank1ng` | 房间号 / 房间名 / 完整链接，可省略 |
| `--room <值>` | — | 同上，显式指定 |
| `--port <端口>` | `8765` | 本地监听端口 |
| `--bitrate <码率>` | `8000` | `8000` 蓝光8M / `4000` 蓝光4M / `2000` 超清 / `1000` 高清 |
| `--open` | 关 | 启动后自动拉起 PotPlayer |
| `--transcode` | 关 | 启用 NVENC 重编码（流畅优先） |
| `--flv` | 关 | 直接输出 FLV（低延迟，不转 HLS） |
| `--fps <帧率>` | 跟随码率 | 重编码目标帧率，8M 档默认 60 |
| `--player <路径>` | 自动探测 | 指定 PotPlayer 可执行文件 |
| `--ffmpeg <路径>` | 自动探测 | 指定 ffmpeg 可执行文件 |

### 环境变量

| 变量 | 作用 |
|------|------|
| `POTPLAYER_PATH` | PotPlayer 完整路径 |
| `FFMPEG_PATH` | ffmpeg 完整路径 |

## 🧠 技术原理

<details>
<summary>点开看实现细节（不看也完全不影响使用）</summary>

### 三个真实痛点，以及怎么解决的

| 痛点 | 现象 | 做法 |
|------|------|------|
| **分块重叠** | 时间戳倒退 → H.264 参考链断裂 → 花屏 | 严格按时间戳去重，只转发更新的帧 |
| **分块间隙** | 30fps 的流只剩 24.7fps | 并发预读 + 1.5 秒无数据就动态补拉 |
| **配置头丢失** | 转封装后没声音 / 被猜成单声道 | 单独缓存并转发 AAC sequence header |

### 关键设计

1. **并发预读** — 每 2 秒发起一条新连接，最多 2~4 条并发，用重叠覆盖 CDN 块之间的间隙
2. **动态补拉** — 1.5 秒没有新内容立即追加连接，应对碎块房间
3. **严格去重** — `if (t.ts <= lastTs) return;` 这一行消掉了全部 `Non-monotonic DTS` 警告
4. **配置头补发** — AVC / AAC 的 sequence header 单独缓存，在 FLV 头之后立即补发

### 处理链路

```
虎牙 CDN（2~8 秒碎块）
        │  并发拉取，每条带随机参数强制回源
        ▼
  Node 中继（huya-relay.js）
        │  按时间戳去重 → 补发配置头 → 重排为连续 FLV
        ▼
  http://127.0.0.1:8765/live.flv
        │
        ├─ 原画直通：ffmpeg -c copy → HLS 分片
        └─ 流畅优先：ffmpeg NVENC + CFR → HLS 分片
        ▼
   PotPlayer / VLC / mpv
```
