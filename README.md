# 虎牙直播 → PotPlayer 本地中继

把虎牙直播间转成本地 HLS 流，用 **PotPlayer / VLC / mpv** 播放。支持 1080p60 原画质、零掉帧、完整立体声音频。

---

## 为什么需要它

虎牙 CDN 对匿名请求按「块」下发，单条连接通常只给 **2~8 秒**就被服务端关闭。直接把直链丢给播放器会报「服务器已关闭」，或者反复缓冲。

本项目在本地起一个中继服务，把碎片化的 CDN 分块拼成**连续流**，再交给播放器。同时解决三个实际痛点：

| 痛点 | 表现 | 本项目做法 |
|------|------|-----------|
| 分块重叠 | 时间戳倒退、H.264 参考链断裂、画面花屏 | 严格按时间戳去重 |
| 分块间隙 | 30fps 的流只剩 24.7fps，画面掉帧 | 并发预读 + 动态补拉 |
| 配置头丢失 | 转封装后没声音（被猜成单声道） | 单独转发 AAC 配置头 |

---

## 特性

- **原画质直通** — 默认 1080p60 / 蓝光8M / H.264 High profile，零二次编码损失
- **零掉帧** — 并发预读 + 动态补拉，实测稳定 60.0fps
- **完整音频** — 正确转发 AAC 配置头，44.1kHz 立体声 / 128kbps
- **三种播放模式** — 原画直通 / 流畅优先（NVENC 重编码）/ 低延迟（FLV）
- **交互式启动** — 双击 bat，输入房间号或链接即可
- **自动探测** — 自动寻找 PotPlayer 和 ffmpeg，无需改任何路径
- **多房间支持** — 房间号、英文房间名、完整链接都行

## 环境要求

### 必需

| 依赖 | 版本 | 说明 |
|------|------|------|
| **Windows** | 10 / 11 | 批处理启动器依赖 cmd |
| **Node.js** | **16 或更高**（推荐 18 / 20 / 22） | 运行中继服务。低于 16 会有兼容问题 |
| **ffmpeg** | 4.x+（推荐 6.x） | HLS 转封装 / 重编码。建议同时带上 `ffprobe`（排查问题时用） |

### 可选

| 依赖 | 说明 |
|------|------|
| **PotPlayer** | 不装也能用，任意播放器打开本地地址即可 |
| **NVIDIA 显卡**（GTX 950 以上） | 仅「流畅优先」模式需要 NVENC 硬件编码 |
| **网络带宽** | 蓝光8M 约需 20Mbps；蓝光4M 约需 10Mbps |

### 检查环境

```bat
node -v          :: 应输出 v16.x 或更高
ffmpeg -version  :: 应输出 ffmpeg version 4.x / 6.x
```

## 安装

### 1. 安装 Node.js

到 [nodejs.org](https://nodejs.org/) 下载 **LTS 版本**（18 或 20），一路下一步即可。

安装完成后打开 cmd 验证：

```bat
node -v
```

### 2. 准备 ffmpeg

**方式 A：复用 PotPlayer 自带的（最省事）**

如果你装了 PotPlayer，它自带 ffmpeg，通常在这个位置：

```
C:\Program Files\DAUM\PotPlayer\Engine\ffmpeg.exe
```

本程序会自动去这个目录找，**不用额外安装**。

**方式 B：下载独立版**

到 [gyan.dev](https://www.gyan.dev/ffmpeg/builds/) 下载 `ffmpeg-release-essentials.zip`，解压后把 `bin` 目录里的 `ffmpeg.exe` 和 `ffprobe.exe` **放到本脚本同一目录**即可。

**方式 C：加入系统 PATH**

下载后把 `bin` 目录加入环境变量 `PATH`，这样任何位置都能调用。

> 验证：打开 cmd 执行 `ffmpeg -version`，能输出版本号就说明配好了。

### 3. 安装 PotPlayer（可选）

到 [potplayer.daum.net](https://potplayer.daum.net/) 下载安装。本程序会自动探测以下位置：

- 脚本同目录 / 上一级目录
- `C:\Program Files\DAUM\PotPlayer\`
- `C:\Program Files (x86)\DAUM\PotPlayer\`
- `%LOCALAPPDATA%\Programs\DAUM\PotPlayer\`

找不到时也可以用 `--player` 参数手动指定。

### 4. 获取本项目

```bat
git clone https://github.com/<你的用户名>/huya-live-relay.git
cd huya-live-relay
```

或者直接下载 ZIP 解压到任意目录。

## 使用

### 方式一：双击启动（推荐）

双击 **`play-huya.bat`**，按提示操作：

```
==========================================
        虎牙直播  -  PotPlayer
==========================================

  请输入直播间，支持三种写法：

    房间号      825803
    房间名      dank1ng
    完整链接    https://www.huya.com/825803

  上次使用: 825803   （直接回车沿用）

  请输入房间: _
```

接着选画质和模式，**全部直接回车 = 最佳配置**。

| 步骤 | 选项 |
|------|------|
| 画质 | `[1]` 蓝光8M（1080p60 原画质，推荐）`[2]` 蓝光4M `[3]` 超清2M |
| 模式 | `[1]` 原画直通（画质无损，推荐）`[2]` 流畅优先（NVENC 重编码）`[3]` 低延迟（FLV） |

程序会自动打开 PotPlayer 播放。**关闭命令行窗口即停止播放。**

### 方式二：命令行

```bat
:: 最简单
node huya-relay.js 825803 --open

:: 指定画质
node huya-relay.js 825803 --bitrate 4000 --open

:: 用完整链接
node huya-relay.js https://www.huya.com/dank1ng --open

:: 换端口（8765 被占用时）
node huya-relay.js 825803 --port 8766 --open
```

启动后也可以手动用任意播放器打开：

- **HLS（推荐）**：`http://127.0.0.1:8765/live.m3u8`
- **FLV（低延迟）**：`http://127.0.0.1:8765/live.flv`

## 参数说明

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `<房间>` | `dank1ng` | 房间号 / 房间名 / 完整链接，可省略 |
| `--room <值>` | — | 同上，显式指定 |
| `--port <端口>` | `8765` | 本地监听端口 |
| `--bitrate <码率>` | `8000` | `8000` 蓝光8M / `4000` 蓝光4M / `2000` 超清 / `1000` 高清 |
| `--open` | 关 | 启动后自动拉起 PotPlayer |
| `--transcode` | 关 | 启用 NVENC 重编码（流畅优先模式） |
| `--flv` | 关 | 直接输出 FLV（低延迟模式，不转 HLS） |
| `--fps <帧率>` | 跟随码率 | 重编码时的目标帧率，8M 档默认 60 |
| `--player <路径>` | 自动探测 | 指定 PotPlayer 可执行文件 |
| `--ffmpeg <路径>` | 自动探测 | 指定 ffmpeg 可执行文件 |

### 环境变量

也可以用环境变量代替参数：

| 变量 | 作用 |
|------|------|
| `POTPLAYER_PATH` | PotPlayer 完整路径 |
| `FFMPEG_PATH` | ffmpeg 完整路径 |

## 三种模式怎么选

| 模式 | 画质 | 流畅度 | 延迟 | 适用场景 |
|------|------|--------|------|---------|
| **原画直通** | ⭐⭐⭐⭐⭐ 无损 | ⭐⭐⭐⭐ | 约 5 秒 | 日常观看，追求画质 |
| **流畅优先** | ⭐⭐⭐⭐ 轻微二次编码 | ⭐⭐⭐⭐⭐ 绝对不掉帧 | 约 7 秒 | 网络不稳、或原画有轻微顿挫时 |
| **低延迟** | ⭐⭐⭐⭐⭐ 无损 | ⭐⭐⭐ | 约 3 秒 | 看比赛、需要跟弹幕同步 |

> **说明**：原画直通是 `-c copy`，画面完全无损；但分片只能在关键帧处切分，时长会在 1.2~3 秒间浮动，个别播放器缓冲策略会因此轻微顿挫。此时换「流畅优先」即可。

## 常见问题

### Q: 提示「端口 8765 被占用」

上次的中继还没退出。程序会自动检测并复用；如果复用的版本不对，手动结束旧进程：

```bat
:: 查看占用
netstat -ano | findstr :8765

:: 结束（把 <PID> 换成上面查到的数字）
taskkill /PID <PID> /F
```

或者换个端口：`play-huya.bat --port 8766`

### Q: 没有声音

已修复（v2.4）。如果仍遇到，确认 ffmpeg 版本 ≥ 4.0。可以用 ffprobe 检查分片：

```bat
ffprobe -i http://127.0.0.1:8765/live.m3u8
```

正常应看到 `Audio: aac (LC), 44100 Hz, stereo`。若显示 `mono` 或 `aac (LTP)`，说明版本过旧。

### Q: 画面卡顿 / 掉帧

按以下顺序排查：

1. **换模式**：原画直通 → 流畅优先（重编码用 CFR 补齐帧）
2. **降码率**：蓝光8M → 蓝光4M（带宽不够时）
3. **确认带宽**：任务管理器看网络占用，8M 档峰值可达 15Mbps
4. **换播放器**：mpv / VLC 对不连续流的容忍度更高

### Q: 找不到 PotPlayer

程序会打印探测结果。三种解决方式：

```bat
:: 1. 指定路径
node huya-relay.js 825803 --player "D:\PotPlayer\PotPlayerMini64.exe" --open

:: 2. 设置环境变量
set POTPLAYER_PATH=D:\PotPlayer\PotPlayerMini64.exe

:: 3. 手动打开（不自动播放）
::    先运行 node huya-relay.js 825803
::    再用播放器打开 http://127.0.0.1:8765/live.m3u8
```

### Q: 主播未开播

程序会提示 `主播当前未开播 (liveStatus=...)`，并持续重试。开播后会自动接上。

### Q: 蓝光8M 反而比 4M 卡

不同码率档的 CDN 分块长度差异很大（实测 8M 档一块只有 2.4 秒，4M 档有 8 秒）。8M 档虽然画质更好，但对带宽和并发要求更高。网络一般时建议选 4M。

## 技术原理

```
虎牙 CDN（2~8 秒碎块）
        │  并发拉取，每条带随机参数强制回源
        ▼
  Node 中继（本程序）
        │  按时间戳去重 → 补发配置头 → 重排为连续 FLV
        ▼
  http://127.0.0.1:8765/live.flv
        │
        ├─ 原画直通：ffmpeg -c copy → HLS 分片
        └─ 流畅优先：ffmpeg NVENC 重编码 + CFR → HLS 分片
        ▼
   PotPlayer / VLC / mpv
```

关键设计：

1. **并发预读**：每 2 秒发起一条新连接，最多 2~4 条并发，覆盖 CDN 块之间的间隙
2. **动态补拉**：1.5 秒没有新内容就立即追加连接，应对碎块房间
3. **严格去重**：只转发时间戳更新的帧，避免 DTS 倒退导致解码器错乱
4. **配置头补发**：AVC / AAC 的 sequence header 单独缓存并转发，保证转封装后音画正常
